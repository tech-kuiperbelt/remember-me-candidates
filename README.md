# Remember Me acceptance candidates

This repository hosts frozen files for independent browser/Finder/Gatekeeper testing. These are acceptance candidates, not official Remember Me releases. Official v1.1.3 remains unpublished until real-Mac acceptance and maintainer GO.

Verify SHA256 from the matching record. Keep Gatekeeper and quarantine enabled. The test DMG must be byte-identical to the archived official Release candidate; no replacement after acceptance is permitted.
